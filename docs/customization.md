# Panduan Kustomisasi Visual Tema

Seluruh pengelolaan pengaturan visual Gesahan News Pro dipusatkan sepenuhnya pada kontrol **WordPress Customizer** (Tampilan > Sesuaikan).

## Bagian Pengaturan Tersedia:
1.  **Skema Warna:**
    *   Mengubah aksen warna primer dari warna default GDS (`#E50914`) ke warna identitas brand media Anda.
2.  **Sistem Tipografi:**
    *   Memilih mode tipografi modern yang responsif: Sans-serif (optimalisasi kecepatan) atau Serif (tingkat keterbacaan artikel tinggi).
3.  **Homepage Builder:**
    *   Menentukan segmen kategori utama yang akan ditarik ke dalam komponen interaktif **Category Block Section**.
4.  **Manajemen Slot Iklan:**
    *   Mencetak script unit periklanan pihak ketiga secara dinamis baik di area header leaderboard maupun bawah artikel.
5.  **Optimasi Performa:**
    *   Mengaktifkan atau menonaktifkan native lazy loading pada pemuatan gambar.
