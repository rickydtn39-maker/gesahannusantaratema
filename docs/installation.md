# Panduan Instalasi Gesahan News Pro v1.0 Enterprise Edition

## Prasyarat Server
*   WordPress versi terbaru (Disarankan 6.2+)
*   PHP Versi 8.2 ke atas
*   MySQL 5.7+ / MariaDB 10.3+

## Cara Instalasi Manual
1.  Unduh folder `gesahan-news-pro` dalam format ZIP.
2.  Masuk ke dashboard WordPress Anda.
3.  Arahkan kursor ke **Tampilan > Tema > Tambah Baru > Unggah Tema**.
4.  Pilih file ZIP tema dan klik **Instal Sekarang**.
5.  Setelah instalasi berhasil, klik **Aktifkan**.

## Setup Awal Tema
1.  Pergi ke **Tampilan > Menu** untuk membuat dan menetapkan navigasi primer ke lokasi **Primary Navigation Menu**.
2.  Masuk ke **Tampilan > Widget** untuk menambahkan widget buatan GDS ke area **Main Sidebar** dan **Footer Column 1**.
