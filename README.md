## Overview

**GusahanNusantara** adalah tema WordPress Portal Berita modern yang dikembangkan menggunakan arsitektur enterprise dengan fokus pada:

- ⚡ Performance First
- 🔍 SEO Optimized
- ♿ Accessibility (WCAG)
- 🏗 Clean Architecture
- 🔒 Security First
- 📱 Mobile First
- 🚀 Core Web Vitals
- 📰 Digital News Publisher

Tema ini dirancang untuk media online profesional, portal berita nasional, media daerah, perusahaan media, hingga organisasi pemerintah.

# Installation

Clone repository

```bash
git clone https://github.com/USERNAME/gusahan-theme.git
```

Masuk ke folder

```bash
cd gusahan-theme
```

Install dependencies

```bash
npm install
```

Jalankan lint

```bash
npm run lint
```

Build

```bash
npm run build
```
